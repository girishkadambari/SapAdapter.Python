# ROADMAP

This document outlines the planned features and improvements for the SAP MCP Adapter.

## Phase 1: Foundation (Current)
- [x] Initial MCP Implementation
- [x] Session & Screen Observation
- [x] Basic Action Dispatching
- [x] Screenshot Support
- [x] Open-source sanitization and documentation

## Phase 2: Enhanced Reliability & DX
- [ ] Comprehensive `pytest` suite for core logic.
- [ ] Mock SAP environment for local development without live SAP.
- [ ] Improved error handling for modal popups.
- [ ] Configuration-driven tool naming and descriptions.
- [ ] Support for SAP GUI 8.00 specifically with 64-bit considerations.

## Phase 3: Advanced Intelligence
- [ ] Automated screen classification using LLMs/VLMs.
- [ ] Auto-discovery of business processes (recording mode).
- [ ] Support for SAP Fiori/WebGUI (potential extension).
- [ ] Multi-session orchestration (syncing multiple windows).
- [ ] Advanced AlvGrid/GridView high-performance extraction.

---
*Note: This roadmap is subject to change based on community feedback and contributions.*
