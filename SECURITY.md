# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do NOT open a public issue. Instead, please report it privately.

**Email**: [your-email@example.com] (Please update with real contact)

### Our Process
1. We will acknowledge receipt within 48 hours.
2. We will investigate the issue and provide an estimated timeline for a fix.
3. Once the fix is verified, we will coordinate a public disclosure with you.

### Responsible Disclosure
We ask that you follow responsible disclosure guidelines and allow us time to fix the issue before sharing it publicly.
